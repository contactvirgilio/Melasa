# Melasa

Touch drum kit for phone and tablet. Open `index.html` in a browser (or host on GitHub Pages).

- Kit: crash, splash, ride, hi-hat, 3 toms, snare, double kick
- Multi-touch, hit the center for louder, the rim for softer
- Sounds are synthesized with Web Audio (no sample files)
- Desktop keys: Q crash, W splash, E ride, A hi-hat, S snare, D/F/G toms, Space kick

Planned: piano.
